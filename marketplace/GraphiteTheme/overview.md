# Graphite Theme

A warm-grey light theme and a near-black dark theme for Visual Studio. Graphite keeps the editor calm while preserving clear semantic separation between declarations, control flow, strings, numbers, operators, and comments.

## Graphite Dark

![Graphite Dark preview](images/GraphiteDark.png)

Graphite Dark uses a low-glare charcoal surface with teal, purple, yellow, and green accents.

## Graphite Light

![Graphite Light preview](images/GraphiteLight.png)

Graphite Light carries the same semantic language onto a warm, paper-like background.

## Features

- Light and dark variants in one extension.
- Bold control keywords and operators for faster structural scanning.
- Italic interfaces, extension methods, and selected semantic classifications.
- Separate colors for comments, strings, numbers, types, functions, properties, and fields.
- AMD64 and ARM64 support for Visual Studio versions 17.9 through 18.x.

## Privacy

Graphite Theme runs entirely inside Visual Studio. It does not collect telemetry, transmit data, or connect to remote services.
