# Focus Themes

Six high-separation dark themes for Visual Studio, designed to make code structure visible before every word is read. Each variant combines a near-black ground with one dominant accent and deliberately separated semantic colors.

## Voltage

![Focus Voltage preview](images/FocusVoltage.png)

Hot-pink control flow, cyan types, lime strings, and violet methods.

## Ultraviolet

![Focus Ultraviolet preview](images/FocusUltraviolet.png)

An electric violet-led palette with sharp cool accents.

## Reactor

![Focus Reactor preview](images/FocusReactor.png)

Radioactive green and warm warning hues on a deep neutral surface.

## Arcade

![Focus Arcade preview](images/FocusArcade.png)

Bright arcade colors with deliberate separation between every token family.

## Signal

![Focus Signal preview](images/FocusSignal.png)

A signal-red accent balanced by cool types and readable literals.

## Nightdive

![Focus Nightdive preview](images/FocusNightdive.png)

Deep-ocean blues and bioluminescent accents for low-glare sessions.

## Features

- Six themes in one extension.
- Strong semantic separation for rapid visual scanning.
- Bold control keywords and operators.
- Italic interfaces, extension methods, and selected semantic classifications.
- AMD64 and ARM64 support for Visual Studio versions 17.9 through 18.x.

## Privacy

Focus Themes runs entirely inside Visual Studio. It does not collect telemetry, transmit data, or connect to remote services.
